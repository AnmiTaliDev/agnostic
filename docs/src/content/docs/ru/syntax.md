## Исходные файлы

Исходный файл — это одна декларация `package`, за которой следуют `import` верхнего уровня и объявления функций и структур. Операторы разделяются переносом строки, а не точкой с запятой. Отступы не имеют значения.

```agn
package main

import "stdio"

func main() {
    stdio.PrintlnStr("Hello, World!")
}
```

Точка входа — функция `main` в `package main`.

## Комментарии

Два вида строчных комментариев, оба до конца строки:

```agn
// комментарий
# тоже комментарий
```

Блочных комментариев нет.

## Импорты

```agn
import "stdio"
import "math"
```

`use` принимается как синоним `import`. О том, как путь импорта превращается в файл, см. [Модули](/ru/modules/).

## Функции

```agn
func add(a int, b int) int {
    return a + b
}
```

`fn` принимается как синоним `func`. Параметры пишутся как `имя тип`, через запятую. Тип возвращаемого значения указывается после списка параметров без стрелки; для функции без возвращаемого значения тип опускается.

Функции, объявленные в импортируемом модуле, должны иметь модификатор `pub`, чтобы быть видимыми снаружи:

```agn
pub fn Max(a int, b int) int {
    if a > b {
        return a
    }
    return b
}
```

Функция модуля без `pub` вообще не проверяется типами и не компилируется при импорте этого модуля. На функции в `package main` `pub` никак не влияет.

## Переменные

```agn
var x int = 5
var y = 5        // тип выводится из инициализатора
var z int        // нулевое значение
```

`let` принимается как синоним `var`. Двоеточие между именем и типом (`var x: int = 5`) допускается, но необязательно.

Присваивание существующей переменной, элементу массива, полю структуры или через указатель делается через `=` без `var`:

```agn
x = 6
arr[0] = 6
point.x = 6
*ptr = 6
```

## Операторы

Арифметика: `+`, `-`, `*`, `/`, `%`. Сравнение: `==`, `!=`, `<`, `<=`, `>`, `>=`. Логика: `&&`, `||`, `!`. Побитовые: `&`, `|`, `^`, `<<`, `>>`. Конкатенация строк: `++` (работает под `--backend=llvm`; `--backend=nvm` отклоняет его на этапе компиляции, вместо него используйте `string.concat`, см. [Стандартную библиотеку](/ru/standard-library/)).

```agn
var greeting string = "foo" ++ "bar"
```

Перегрузки операторов нет.

## Литералы

Целочисленные литералы только десятичные: `0`, `42`, `1000000`. Нет ни шестнадцатеричной, ни восьмеричной, ни двоичной записи. Литерал с десятичной точкой (`3.14`) — это литерал `f64`; см. [Типы](/ru/types/).

Строковые литералы в двойных кавычках, с escape-последовательностями `\n`, `\t`, `\r`, `\\`, `\"`:

```agn
var s string = "line one\nline two"
```

Индексация строки даёт байт в этой позиции как целое число:

```agn
var c int = "hello"[0]   // 104, значение байта 'h'
```

## Интерполяция строк

Строковый литерал с `$(expr)` внутри — это шаблонная строка: выражение вычисляется, и его текстовое представление подставляется на это место.

```agn
var name string = "Agnostic"
var n int = 42
stdio.PrintlnStr("hello $(name), value=$(n)")
```

У подставляемого выражения после двоеточия может быть спецификатор формата: необязательный ведущий `0` для дополнения нулями, необязательная ширина и один из символов `d` (десятичное), `x` (шестнадцатеричное строчными), `X` (шестнадцатеричное прописными) или `s` (строка).

```agn
stdio.PrintlnStr("value=$(n:05d)")   // value=00042
```

Шаблонные строки вычисляются во время выполнения и доступны только под `--backend=llvm`; `--backend=nvm` отклоняет их на этапе компиляции.
